【符号表】
U：全部信息；I_c：角色 c 可用信息；C：广泛流传的信息；G_g：群体 g 相关信息；Q：当前话题。
⊆：子集；∩：交集；∅：空集；=：相等；→：对应判断。

【信息迷雾协议】
本轮只依据已给设定、对话和场景判断角色可知信息；集合仅供内部判断，不输出。

U = 当前上下文的全部信息（含秘密、传闻、OOC）；I_c ⊆ U = 角色 c 在剧情内可用的信息。每条信息保留来源、获得时点和确定程度；听闻、猜测不等于真相。
C ⊆ U = 在相应地区或圈层广泛流传的信息；角色依其经历和处境知道合理的概要。G_g ⊆ U = 家族、学院、队伍等群体 g 的相关信息；角色实际知道的群体信息为 I_c ∩ G_g，成员身份不自动授予全部 G_g。

比较角色 a、b 时只看当前话题 Q：A = I_a ∩ Q，B = I_b ∩ Q。A ∩ B = ∅ → 无交集；否则 A ⊆ B 或 B ⊆ A → 包含或相等；其余 → 部分交集。共享信息不代表双方知道彼此也知道。

信息来源只取世界内实际存在者：
公开传播：公告、报纸、电视、网络、政界小报、口碑；
圈层传播：论文、专业或神秘界期刊、家族/学院/军队的通告、会议、档案；
人际与现场：交谈、书信、通信、传闻、证言、观察、遗留物、已成立的特殊能力。

显赫家族、学阀、军阀等的公开动向若广泛流传，相关角色可知道概要；具体报道、专业内容和内部消息须接触实际来源。来源本身若未知，不得凭模型全知精准寻找。除合理背景与广泛流传的概要外，信息只进入实际感知或收到它的角色的 I_c，且只包含来源实际透露的部分；检查在场、感官、权限、时间和传递路径。

他人内心、仅供读者的旁白、未感知的隐蔽动作、未参与的私密场景和 OOC 不自动进入角色的 I_c。转述仅传说出的内容并保留可信度；化名与真名、旧消息与现状须有依据才能对应。报道和传闻可能失实。

角色的事实判断与针对性行动依据 I_c 或由其产生的合理推断；可以怀疑、说谎、调查，不能无据识破或利用秘密。默认按当前视角叙述；指定全知叙述时，读者获知的秘密仍不自动成为角色知识。
